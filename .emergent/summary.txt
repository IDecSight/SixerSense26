<analysis>**original_problem_statement:**
The user wants to build a mobile-first, AI-powered gamified productivity app called **Sixer Sense**.

**PRODUCT REQUIREMENTS:**

*   **Vision:** Turn daily productivity into a cricket match where tasks are balls, completing them scores runs, and distractions cause wickets. The AI acts as a captain, opponent, and coach.
*   **Core Gameplay:**
    *   **Match Formats:** T20 (20 overs), ODI (50 overs), Test Match (unlimited overs).
    *   **AI Opponent:** Sets a target score that increases with user wins/level-ups.
    *   **Task Logic:** Tasks are categorized (Health, Career, Finance, etc.) and have run values (1, 4, 6). 6 tasks = 1 over. 10 wickets per match. A match must complete within one calendar day.
    *   **Balls vs. Tasks:** Balls are units of effort (5-15 mins), not a 1:1 task count. A large task can consume multiple balls.
*   **Player Model:** Each user has a virtual team of 11 players representing life categories, which influences task generation.
*   **User Tiers:**
    *   **Free:** Play with virtual runs only.
    *   **Premium:** Can add money, convert to runs, and unlock features. Upgrade should be via a real payment gateway (DodoPayments).
*   **Authentication:** Google Sign-In and Email/Password.
*   **Core Screens:** Login/Landing, Home, Dashboard (Today's Match), Add Task, AI Recommendations, Post-Match Summary, Match History, Settings, Wallet.
*   **AI Features:** The AI should recommend tasks, affiliate products (localized by country/currency), and provide live cricket-style commentary on user actions.

**User's preferred language**: English

**what currently exists?**
The Sixer Sense MVP is built with a React frontend, FastAPI backend, and MongoDB. The application has a glossy royal blue gradient theme with green and white text accents.

Key implemented features include:
- Google Sign-In and a comprehensive landing page.
- A central Home page that navigates to the Dashboard, Wallet, and Profile.
- Core gameplay loop: Users can select a match format (T20, ODI, Test), receive tasks, complete them to score runs, and see their score update on a scoreboard.
- Daily match mechanics: Matches automatically refresh daily, and users can manually restart a match.
- Advanced game mechanics (backend): A Player Model (11 players per user), the concept of balls as units of effort, and dynamic over distribution throughout the day.
- AI-driven features:

- A functional wallet system where users can upgrade to a Premium plan (mocked, payment integration pending) and see transaction history.
- Currency is set to INR (₹) across the application.
- A  page exists to help test match states.
